Visual Studio를 이용한 나만의 Agent 만들기

w/ Claude Code

대상: 중학생

Visual Studio란 무엇인가?

  • Visual Studio는 마이크로소프트(Microsoft)가 만든 프로그램이에요
  • 한글이나 워드로 글을 쓰듯, 이 프로그램 안에서 '코드'(컴퓨터에게 시키는 명령어)를 써요
  • 코드를 쓰고, 잘못된 부분을 찾아 고치고, 실제로 실행해보는 것까지 한 프로그램에서 다 할 수 있어요
  • 무료로 쓸 수 있는 버전(Community)이 있어서 학생도 설치해서 바로 써볼 수 있어요
  • 2026년형 최신 버전은 AI 도우미가 기본으로 들어있어서, 코드를 짤 때 옆에서 같이 도와줘요
용어 설명코드(Code) 컴퓨터에게 무엇을 하라고 알려주는 명령어 모음  ·  IDE 코드를 쓰고 실행하고 오류를 찾는 걸 한 프로그램에서 다 할 수 있게 해주는 도구. Visual Studio가 대표적인 IDE예요
출처: Microsoft Learn, Visual Studio Magazine (2026)

Visual Studio 기능 및 설명

  • 자동 완성 — 코드를 치다 보면 다음에 올 말을 미리 알려줘서 더 빠르게 쓸 수 있어요
  • 디버깅 — 코드에서 잘못된 부분(버그)을 찾아서 고칠 수 있게 도와줘요
  • Git 연동 — 내가 만든 코드를 저장하고, 예전 버전으로 되돌리는 것도 할 수 있어요
  • 테스트 기능 — 내가 만든 프로그램이 제대로 작동하는지 자동으로 확인해줘요
  • AI 채팅(Copilot) — 궁금한 걸 물어보면 AI가 코드를 대신 써주거나 설명해줘요
  • 다양한 테마 — 눈이 편안한 여러 색 화면 중에서 고를 수 있어요
  • 확장 기능 — 스마트폰에 앱을 설치하듯, 필요한 기능을 나중에 더 추가할 수 있어요
용어 설명버그(Bug) 프로그램에서 잘못 작동하는 부분  ·  디버깅 버그를 찾아서 고치는 작업  ·  Git 코드를 저장하고 여러 버전을 관리해주는 도구

JSON이란 무엇인가?

  • JSON은 컴퓨터끼리 정보를 주고받을 때 자주 쓰는 '간단한 메모 형식'이에요
  • 예를 들어 '이름: 홍길동, 나이: 14'처럼 이름표와 내용을 짝지어 적어요
  • 사람이 읽기도 쉽고, 어떤 프로그래밍 언어에서도 쉽게 사용할 수 있어요
  • 웹사이트에서 정보를 받아올 때나, 프로그램 설정을 저장할 때 자주 사용해요
  • Visual Studio와 Claude Code도 설정 파일을 이 JSON 형식으로 만들어요
{
  "name": "PT Agent",
  "sections": ["intro", "demo"]
}
용어 설명이름표-내용(Key-Value) '이름표: 내용'처럼 한 쌍으로 짝지어 정보를 적는 방식  ·  설정 파일 프로그램이 어떻게 동작할지 미리 정해놓은 파일

Claude Code란 무엇인가?

  • Claude Code는 Anthropic이라는 회사가 만든, 대화로 코드를 작성해주는 AI 프로그램이에요
  • 사람이 '이런 기능 만들어줘'라고 말하면, AI가 알아서 코드를 쓰고 고쳐줘요
  • 여러 개의 파일을 한 번에 보고 이해해서, 큰 프로그램도 함께 도와줄 수 있어요
  • 실행하기 전에 '이렇게 할게요'라는 계획을 먼저 보여주고, 확인한 다음 진행할 수 있어요
  • Visual Studio 같은 프로그램 안에서 함께 사용할 수 있어요
용어 설명AI 에이전트 스스로 판단해서 여러 작업을 척척 해내는 AI 프로그램  ·  Plan Mode AI가 작업을 하기 전에 계획을 먼저 보여주는 기능
출처: Anthropic Claude Code Docs, GitHub anthropics/claude-code

Visual Studio와 Claude Code를 이용하는 방법

  • 방법 1 — Visual Studio(또는 VS Code)에 Claude Code 확장 프로그램을 설치해요
  • 방법 2 — 프로그램 안의 '터미널'에 claude 라고 입력하면 바로 연결돼요
  • '이 파일을 고쳐줘'처럼 원하는 부분을 콕 집어서 요청할 수 있어요
  • AI가 고친 부분은 색깔로 표시돼서, 확인하고 승인할 수 있어요
  • 복잡한 작업은 계획을 먼저 세우고 나서 진행해요
  • 자주 쓰는 규칙을 한 번 적어두면, 매번 설명하지 않아도 AI가 기억해줘요
용어 설명터미널 글자로 명령어를 입력해서 컴퓨터에게 일을 시키는 화면  ·  확장 프로그램 원래 프로그램에 새 기능을 더해주는 부가 프로그램

GitHub는 무엇이며 주로 이용하는 무료 API 및 Tool

  • GitHub는 내가 만든 코드를 인터넷에 저장하고, 다른 사람과 함께 만들 수 있는 사이트예요
  • GitHub Pages — 내가 만든 웹페이지를 무료로 인터넷에 올려서 누구나 볼 수 있게 해줘요
  • GitHub Actions — '코드를 올리면 자동으로 이 작업을 해줘'처럼, 반복되는 일을 자동으로 처리해줘요
  • API — 다른 프로그램(예: 카카오톡)과 정보를 주고받을 수 있게 해주는 통로예요
  • gh(깃허브 CLI) — 마우스 없이 글자 명령만으로 깃허브를 다룰 수 있는 도구예요
용어 설명저장소(Repository) 코드와 파일들을 모아두는 폴더 같은 공간  ·  API 서로 다른 프로그램이 정보를 주고받을 수 있게 해주는 규칙과 통로  ·  자동화 사람이 매번 하지 않아도 컴퓨터가 알아서 반복 작업을 해주는 것

실습: 매일 영어회화를 나만의 웹페이지로 만들기

  • 목표 — 매일 새로운 영어 회화 문장을 자동으로 만들어서 웹페이지에 올리고, 카카오톡으로 알려주기
  • ① Claude Code와 GitHub Actions가 매일 정해진 시간에 영어 문장과 뜻을 자동으로 만들어요
  • ② 만들어진 내용을 웹페이지(HTML)로 저장해서 GitHub Pages에 자동으로 올려요
  • ③ 카카오톡 API를 이용해서, 완성된 웹페이지 주소를 내 카카오톡으로 보내줘요
  • 준비물 — GitHub 계정과 저장소, 카카오 개발자 사이트에서 발급받은 열쇠(API 키)
  • 더 해보고 싶다면 — 문제 수준 선택하기, 발음 듣기 추가하기, 친구들과 함께 보기
용어 설명API 키 내 계정임을 증명해서 서비스를 사용할 수 있게 해주는 비밀번호 같은 값  ·  GitHub Actions 정해진 시간이나 조건이 되면 컴퓨터가 스스로 작업을 실행해주는 기능
출처: Kakao Developers REST API 문서(카카오톡 메시지)

정리

  • Visual Studio는 코드를 쉽게 짤 수 있게 도와주는 프로그램이고, Claude Code는 AI로 코드를 대신 써주는 도우미예요
  • JSON과 GitHub의 무료 도구들을 함께 쓰면, 서버 없이도 나만의 자동화 프로그램(에이전트)을 만들 수 있어요
  • 오늘처럼 '매일 영어회화 웹페이지'같은 재미있는 아이디어를 직접 만들어 보세요!

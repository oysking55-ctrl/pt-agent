VS Code를 이용한 Agent만들기 개념 정리

w/ Claude Code

대상: 대학생/일반인

오늘의 이야기 — 챗봇은 쓰는데, 이 낯선 용어들은 뭐지?

  • ChatGPT, Gemini, Claude, 젠스파크 같은 범용 AI 챗봇은 이제 많은 사람이 익숙하게 쓰고 있어요
  • 그런데 요즘은 한 걸음 더 나아가 VS Code와 Claude Code로 'daily-english', 'ict공고검색', '회의록 정리' 같은 나만의 Agent를 만드는 사람들이 늘고 있어요
  • 문제는 Claude Code가 시키는 대로 따라만 했지, VS Code가 뭔지 Python은 뭔지 JSON은 뭔지 GitHub는 왜 쓰는지 잘 모른다는 점이에요
  • 개념을 모르고 따라 하면, 결과가 조금만 이상해져도 어디서 문제가 생겼는지 짐작조차 할 수 없어요
  • 오늘은 이 용어들을 하나씩 뜯어보면서, 내가 만든 Agent가 '왜 이렇게 만들어지는지' 이해하는 시간을 가져볼게요
용어 설명Agent(에이전트) 목표를 주면 스스로 계획을 세우고 작업을 끝까지 수행하는 AI 프로그램
시나리오 도입 슬라이드 — 청중의 공감을 이끌어내는 목적

"Agent"란 정확히 무엇인가?

  • 챗봇은 내가 질문할 때마다 답을 주는 '대화형' AI예요 — 매번 내가 직접 물어봐야 움직여요
  • Agent는 목표를 한 번 주면, 스스로 계획을 세우고 필요한 도구를 사용해서 작업을 끝까지 완료하는 AI예요
  • 예를 들어 daily-english Agent는 매일 영어 문장을 찾아 정리하고, ict공고검색 Agent는 공고 사이트를 돌아다니며 새 글을 모아줘요
  • 회의록 정리 Agent는 회의 내용을 읽어서 알아서 요약하고 할 일 목록까지 만들어줘요
  • 핵심 차이는 '반복'과 '자동화'예요 — 챗봇은 한 번의 질문과 답변이고, Agent는 정해진 절차를 스스로 계속 수행해요
  • 2026년의 AI 트렌드도 '대화형 도구'에서 '목표를 끝까지 완수하는 실무형 Agent'로 옮겨가고 있어요
  • 이런 Agent를 만들려면, 내가 원하는 절차를 컴퓨터가 이해할 수 있는 형태로 적어둬야 해요 — 그게 오늘 배울 도구들이에요
용어 설명Agent(에이전트) 목표를 주면 스스로 계획을 세우고, 필요한 도구를 사용해 작업을 끝까지 수행하는 AI  ·  자동화 사람이 매번 반복하던 작업을 컴퓨터가 스스로 처리하도록 만드는 것
출처: AI 에이전트 vs 챗봇 비교 자료 종합(Salesforce, Sendbird, TILNOTE 등, 2026)

VS Code란 무엇인가?

  • VS Code(Visual Studio Code)는 마이크로소프트가 만든 무료 코드 편집기예요
  • 글을 쓰는 워드프로세서처럼, 코드를 쓰고 확인하는 '작업대' 같은 프로그램이라고 생각하면 돼요
  • Windows, macOS, Linux 어디서든 설치해서 쓸 수 있고, 완전히 무료예요
  • 확장 프로그램(Extension)을 설치하면 원하는 기능을 자유롭게 더할 수 있어요 — Claude Code도 이 확장 프로그램 중 하나예요
  • 코드를 쓰는 화면, 결과를 실행하는 터미널, 파일 변경을 관리하는 Git 기능이 한 화면 안에 모두 들어있어요
  • 즉, VS Code는 Agent를 만드는 모든 작업이 실제로 이뤄지는 '작업 공간'이에요
용어 설명코드 편집기 프로그램의 코드를 쓰고, 실행하고, 오류를 고칠 수 있게 해주는 프로그램  ·  확장 프로그램(Extension) 원래 프로그램에 새 기능을 더해주는 부가 프로그램  ·  터미널 화면의 버튼 대신 글자로 된 명령어를 입력해서 컴퓨터에 일을 시키는 창
출처: Microsoft Learn - Visual Studio 2026 릴리스 정보, VS Code 공식 문서 및 초보자 가이드 종합

Claude Code란 무엇인가?

  • Claude Code는 Anthropic이 만든, 대화로 코드를 작성해주는 AI 프로그램이에요
  • VS Code 안에 사이드바 형태로 설치돼서, "이런 Agent를 만들어줘"라고 말로 요청하면 코드를 대신 써줘요
  • 파일을 고치기 전에 바뀌는 내용을 화면에 보여주는 '인라인 diff'로, 무엇이 바뀌는지 확인하고 승인할 수 있어요
  • 여러 파일을 한 번에 읽고 이해해서, daily-english처럼 여러 파일로 이루어진 Agent도 한 번에 만들 수 있어요
  • 코드를 바꾼 기록을 체크포인트로 남겨서, 결과가 마음에 안 들면 이전 상태로 되돌릴 수 있어요
  • 결국 Claude Code는 VS Code라는 작업대 위에서 실제로 코드를 써 주는 '동료'의 역할을 해요
용어 설명인라인 diff 코드에서 무엇이 어떻게 바뀌는지 편집 화면 안에서 바로 비교해서 보여주는 기능  ·  체크포인트(Checkpoint) 작업 중간중간 상태를 저장해두어, 필요하면 그 시점으로 되돌릴 수 있게 하는 기록
출처: Claude Code Docs - Use Claude Code in VS Code(code.claude.com), VS Code Marketplace

Python이란 무엇인가?

  • Python은 Claude Code가 Agent를 만들 때 가장 많이 사용하는 프로그래밍 언어예요
  • 문법이 사람이 쓰는 문장과 비슷해서, 여러 프로그래밍 언어 중에서도 특히 읽고 배우기 쉬운 편이에요
  • daily-english가 매일 영어 문장을 찾아오는 절차, 회의록을 요약하는 절차처럼 '순서대로 실행되는 명령'을 적어둔 것이 바로 Python 코드예요
  • 코드를 쓰자마자 바로 실행해서 결과를 확인할 수 있어요 — 별도로 변환하는 과정이 필요 없어요
  • 데이터 정리, 웹사이트 정보 가져오기, 파일 자동 처리 등 Agent에 필요한 대부분의 작업을 Python 코드로 처리할 수 있어요
  • 내가 Python 문법을 몰라도, 원하는 절차를 말로 설명하면 Claude Code가 Python 코드로 바꿔서 만들어줘요
용어 설명프로그래밍 언어 사람이 원하는 작업을 컴퓨터가 이해하고 실행할 수 있는 형태로 적는 약속된 문법
출처: 파이썬 특징 정리(가비아 라이브러리, AWS What is Python 등 종합)

JSON이란 무엇인가?

  • JSON은 사람도 읽을 수 있고 컴퓨터도 이해할 수 있는, 데이터를 정리해서 담는 '규격화된 상자' 같은 형식이에요
  • "이름": "값" 처럼 이름과 값을 짝지어 저장해서, Agent에게 필요한 설정이나 결과를 정리해 담아둬요
  • ict공고검색 Agent가 찾아온 공고 목록, daily-english Agent가 오늘 고른 문장 같은 결과를 JSON 파일에 정리해서 저장해요
  • Python 코드가 '어떻게 할지'를 담당한다면, JSON은 '무엇을, 어떤 값으로'를 담당한다고 볼 수 있어요
  • 확장자는 .json이고, 메모장 같은 평범한 텍스트 편집기로도 열어서 내용을 바로 확인할 수 있어요
  • 값을 자유롭게 추가하거나 바꿀 수 있어서, Agent의 설정을 바꾸고 싶을 때도 JSON 파일만 고치면 되는 경우가 많아요
용어 설명JSON 이름과 값을 짝지어 데이터를 정리해 저장하는, 사람도 컴퓨터도 읽을 수 있는 텍스트 형식  ·  값(Value) 이름표(이름)에 짝지어 저장된 실제 내용, 예: "검색어": "ICT 공고" 에서 'ICT 공고'
출처: MDN - JSON으로 작업하기, ITWorld JSON 데이터 포맷의 이해

GitHub란 무엇인가?

  • Git은 코드가 바뀐 기록을 계속 저장해서, 예전 버전으로 되돌리거나 누가 무엇을 바꿨는지 추적할 수 있게 해주는 도구예요
  • GitHub는 이 Git을 인터넷에서 쓸 수 있게 만든 사이트로, 내 코드를 저장하고 다른 사람과 공유할 수 있어요
  • 내가 만든 Agent 코드를 저장소(Repository)에 올려두면, 컴퓨터가 바뀌어도 언제든 다시 내려받아 쓸 수 있어요
  • GitHub Pages 기능을 쓰면, Agent가 만든 결과를 별도 서버 없이도 웹페이지로 무료로 공개할 수 있어요
  • 여러 명이 함께 Agent를 개선할 때도 누가 무엇을 바꿨는지 기록이 남아서, 안전하게 협업할 수 있어요
  • 정리하면 GitHub는 '내가 만든 Agent를 안전하게 보관하고, 필요하면 다른 사람과 나누는 창고'예요
용어 설명Git 코드가 바뀐 기록을 계속 저장해서, 예전 버전으로 되돌리거나 변경 내역을 추적하게 해주는 도구  ·  저장소(Repository) 코드와 파일들을 모아두는 폴더 같은 공간  ·  GitHub Pages GitHub에 저장된 파일을 별도 서버 없이 무료로 웹페이지처럼 볼 수 있게 해주는 기능
출처: 깃허브 위키백과, Git과 GitHub 기본 개념 정리(모두의연구소, f-lab 등 종합)

→
② VS Code
→
③ Claude Code
→
④ Python 코드
→
⑤ JSON 설정
→
⑥ 실행 → GitHub
  • ① 아이디어 정하기 — 내가 반복하는 업무를 "매일 영어 문장을 찾아줘"처럼 정확한 말로 정리해요
  • ② VS Code 열기 — 작업할 폴더를 열어 코드를 쓰고 실행할 작업 공간을 준비해요
  • ③ Claude Code에게 요청 — 사이드바에서 원하는 Agent를 말로 설명해요
  • ④ Python 코드 생성 — Claude Code가 요청받은 동작을 실제로 수행하는 Python 코드를 작성해줘요
  • ⑤ 설정은 JSON으로 정리 — 검색어, 저장 위치 같은 값을 JSON 파일에 담아 쉽게 바꿀 수 있게 해요
  • ⑥ 실행·확인 후 GitHub에 저장 — 결과를 확인하고, 완성되면 저장소에 올려 다음에도 다시 쓰고 공유해요
요청에 따라 추가된 '한눈에 보는 개념 정리' 장표 — 앞선 6개 개념(VS Code/Claude Code/Python/JSON/GitHub 등)이 실제 제작 흐름에서 각각 어디에 쓰이는지 통합 정리

오늘부터 달라지는 것

  • 지금까지는 Claude Code가 만들어준 결과만 보고, "왜 이렇게 되는지"는 몰라도 그냥 썼을 수 있어요
  • 이제는 VS Code가 작업 공간이고, Claude Code가 코드를 써주는 동료이고, Python이 실제로 움직이는 언어라는 걸 알게 됐어요
  • JSON은 설정과 데이터를 담는 상자, GitHub는 완성된 결과를 보관하고 공유하는 창고라는 것도 이해했어요
  • 결과가 이상할 때 "이게 Python 코드 문제인지, JSON 설정 문제인지"를 짐작하고 더 구체적으로 요청할 수 있게 돼요
  • 개념을 알면 Claude Code에게 더 정확하게 요청할 수 있고, 새로운 Agent도 스스로 설계해볼 수 있어요

정리 & 다음 스텝

  • 범용 챗봇을 넘어, VS Code와 Claude Code로 daily-english, ict공고검색, 회의록 정리 같은 나만의 Agent를 만드는 시대가 됐어요
  • Agent를 만드는 과정은 VS Code(작업 공간) → Claude Code(요청) → Python(동작)·JSON(설정) → 실행/테스트 → GitHub(저장·공유)로 이어져요
  • 오늘 배운 개념을 알면, 시키는 대로 따라 하는 게 아니라 이해하고 직접 설계하는 사람이 될 수 있어요
  • 지금 반복하고 있는 업무 하나를 골라서, 오늘 배운 흐름대로 나만의 Agent를 직접 만들어보세요!

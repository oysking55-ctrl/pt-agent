Visual Studio를 이용한 나만의 Agent 만들기

w/ Claude Code

대상: 대학생/일반인

오늘의 이야기 — 다시 출근, 그리고 반복되는 엑셀 업무

  • 10년간 경력이 끊겼다가 세무사 사무실에 새로 출근하게 된 상황을 가정해볼게요
  • 세무사 사무실에는 거래처 명세서 정리, 매출·매입 자료 취합처럼 매달 똑같이 반복되는 엑셀 작업이 많아요
  • 손으로 하나하나 복사·붙여넣기를 하다 보면 시간도 오래 걸리고 실수도 생기기 쉬워요
  • 오늘은 이런 반복 작업을 Visual Studio와 Claude Code로 자동화하는 방법을 처음부터 배워볼 거예요
  • 프로그래밍을 몰라도 괜찮아요 — 하고 싶은 일을 말로 설명하면 AI가 대신 코드를 만들어줘요
용어 설명자동화 사람이 매번 반복하던 작업을 컴퓨터가 스스로 처리하도록 만드는 것
시나리오 도입 슬라이드 — 청중의 공감을 이끌어내는 목적

왜 자동화가 필요할까? — 세무사 사무실 엑셀 업무의 현실

  • 매달 여러 거래처에서 보내온 엑셀 파일을 하나로 합치는 작업을 반복해야 해요
  • 파일마다 열 순서나 서식이 조금씩 달라서, 손으로 맞추다 보면 시간이 오래 걸려요
  • 홈택스에서 받은 자료와 회사 자체 엑셀 자료를 대조하는 일도 매번 같은 방식으로 되풀이돼요
  • 사람이 직접 복사·붙여넣기를 반복하면 오탈자나 숫자 오류 같은 실수가 생기기 쉬워요
  • 이런 '패턴이 있는 반복 작업'은 컴퓨터가 사람보다 훨씬 빠르고 정확하게 처리할 수 있어요
  • 실제로 세무사 사무실에서 반복 업무를 자동화해 별도 인력 없이도 업무를 처리한 사례가 있어요
용어 설명홈택스 국세청이 운영하는 세금 신고·조회 웹사이트
출처: 세무 업무 자동화 사례 검색 결과 종합(2026)

Visual Studio란 무엇인가?

  • Visual Studio는 마이크로소프트가 만든 대표적인 코드 편집 프로그램(IDE)이에요
  • 코드를 쓰고, 실행하고, 오류를 찾아 고치는 과정을 한 프로그램 안에서 모두 할 수 있어요
  • 개인 개발자나 학생은 Community 버전을 무료로 설치해서 바로 쓸 수 있어요
  • 가볍게 시작하고 싶다면, 더 단순한 버전인 VS Code(Visual Studio Code)를 써도 좋아요
  • 2026년형 최신 버전은 Fluent UI로 화면이 더 깔끔해졌고, AI 도우미 기능이 기본으로 들어있어요
  • 필요한 구성 요소만 골라 설치할 수 있어서, 컴퓨터 용량을 아낄 수 있어요
용어 설명IDE 코드 작성, 실행, 오류 수정까지 한 프로그램 안에서 해결할 수 있게 해주는 통합 개발 도구  ·  Community 버전 개인, 학생, 소규모 팀이 무료로 쓸 수 있는 Visual Studio 버전
출처: Microsoft Learn - Visual Studio 2026 릴리스 정보, visualstudio.microsoft.com

Claude Code란 무엇인가?

  • Claude Code는 Anthropic이 만든, '대화로 코드를 작성해주는' AI 프로그램이에요
  • "이 엑셀 파일들을 하나로 합쳐줘"처럼 사람 말로 요청하면, AI가 알아서 코드를 쓰고 실행까지 도와줘요
  • 터미널(CLI), VS Code/Visual Studio 확장 프로그램, 데스크톱 앱 등 여러 방식으로 사용할 수 있어요
  • 여러 파일을 한 번에 읽고 이해할 수 있어서, 여러 개의 엑셀 파일이 얽힌 작업도 맡길 수 있어요
  • 코드를 바로 실행하기 전에 "이렇게 할게요"라는 계획을 먼저 보여주고 확인받을 수 있어요(Plan Mode)
  • 코딩을 몰라도, 하고 싶은 일을 우리말로 정확히 설명할 수 있으면 충분히 활용할 수 있어요
용어 설명CLI 화면의 버튼 대신 글자로 된 명령어로 컴퓨터에게 일을 시키는 방식  ·  Plan Mode AI가 작업을 실행하기 전에 계획을 먼저 보여주는 기능
출처: Anthropic, Claude Code Docs(code.claude.com)

설치하고 연결하기 — Visual Studio(VS Code) + Claude Code

  • ① Visual Studio 또는 VS Code를 공식 홈페이지에서 내려받아 설치해요 (Community 버전은 무료예요)
  • ② 확장 프로그램(Extensions) 메뉴에서 'Claude Code'를 검색해 설치해요
  • ③ 프로그램 안의 '터미널' 창에 claude 라고 입력하면 Claude Code가 바로 연결돼요
  • ④ Anthropic 계정으로 로그인하면 준비가 끝나요 (Pro 요금제 또는 API 키가 필요해요)
  • ⑤ 자동화하고 싶은 엑셀 파일들을 모아둔 폴더를 열어서 작업을 시작해요
  • 설치가 처음이라면 화면에 나오는 안내를 그대로 따라가기만 하면 돼요, 어려운 설정은 필요 없어요
용어 설명확장 프로그램 원래 프로그램에 새 기능을 더해주는 부가 프로그램  ·  API 키 내 계정임을 증명해서 서비스를 사용할 수 있게 해주는 비밀번호 같은 값
출처: Claude Code Docs - Use Claude Code in VS Code, VS Code Marketplace

Claude Code에게 엑셀 자동화 시키는 법

  • 하고 싶은 작업을 구체적으로 설명할수록 원하는 결과가 정확하게 나와요
  • 예시 — "이 폴더에 있는 엑셀 파일들을 모두 읽어서, 같은 형식으로 합쳐 하나의 파일로 만들어줘"
  • 파일 이름, 열 이름, 원하는 결과 형태(합계, 표 등)를 구체적으로 알려주면 더 좋아요
  • Claude Code가 만든 코드를 실행하기 전에 어떤 내용인지 먼저 보여주니, 확인하고 승인하면 돼요
  • 결과가 마음에 안 들면 "이 부분만 다르게 해줘"처럼 추가로 수정을 요청할 수 있어요
  • 한 번 만들어진 자동화 코드는 다음에도 똑같이 재사용할 수 있어요

실습: 반복 엑셀 작업 자동화 툴 만들기

  • 목표 — 여러 거래처의 엑셀 파일을 매달 하나로 합쳐서 정리하는 나만의 자동화 툴 만들기
  • ① Claude Code에게 "여러 엑셀 파일을 읽어서 하나로 합치고 새 파일로 저장해줘"라고 요청해요
  • ② Claude Code가 만들어준 파이썬(Python) 코드를 실행 버튼으로 바로 돌려서 결과를 확인해요
  • ③ 합쳐진 결과에 거래처별 합계나 서식을 추가해달라고 요청하면 코드를 더 다듬어줘요
  • ④ 실제 업무 파일로 여러 번 테스트하면서, 원하는 결과가 나올 때까지 수정해요
  • 코드를 직접 몰라도 괜찮아요 — 결과를 보고 "이 부분이 이상해"라고 말하면 AI가 고쳐줘요
import glob
import pandas as pd

files = glob.glob("거래처_자료/*.xlsx")
tables = [pd.read_excel(f) for f in files]
merged = pd.concat(tables, ignore_index=True)
merged.to_excel("합계_결과.xlsx", index=False)
용어 설명pandas 엑셀 같은 표 형태 데이터를 파이썬에서 쉽게 다룰 수 있게 해주는 도구 모음  ·  파이썬(Python) 문법이 쉬워서 초보자도 많이 배우는 프로그래밍 언어

만든 자동화 툴 계속 사용하기

  • 한 번 완성한 코드는 파일로 저장해두면 다음 달에도 똑같이 다시 쓸 수 있어요
  • 매번 Visual Studio를 열지 않아도, 더블클릭 한 번으로 실행되게 만들 수 있어요(배치 파일, .bat)
  • PyInstaller 같은 도구를 쓰면 파이썬이 설치 안 된 컴퓨터에서도 실행 파일(.exe)로 돌릴 수 있어요
  • 파일 이름이나 폴더 위치만 바뀌는 작업이라면, Claude Code에게 "경로만 바꿔서 다시 실행해줘"라고 요청하면 돼요
  • 자주 쓰는 규칙(예: 항상 이 폴더의 파일을 정리해줘)을 적어두면 AI가 기억해서 다음에도 똑같이 도와줘요
  • 반복되는 마감 작업일수록, 한 번 만든 자동화 툴이 오랫동안 시간을 절약해줘요
용어 설명배치 파일(.bat) 여러 명령어를 순서대로 실행하도록 적어둔 파일. 더블클릭하면 바로 실행돼요  ·  실행 파일(.exe) 파이썬 같은 프로그램이 없어도 컴퓨터에서 바로 실행할 수 있게 만든 독립 파일
출처: PyInstaller 공식 문서, wikidocs 파이썬 실행 파일 만들기 가이드

결과를 웹페이지에서 확인하기

  • 자동화한 결과를 나만 보지 않고, 웹페이지로 만들어 팀원들과 함께 볼 수도 있어요
  • GitHub는 내가 만든 코드나 파일을 인터넷에 저장하고 관리할 수 있는 무료 사이트예요
  • GitHub Pages를 이용하면 별도의 서버 없이도 내가 만든 웹페이지를 무료로 인터넷에 올릴 수 있어요
  • Claude Code에게 "이 결과를 표로 보여주는 웹페이지를 만들어줘"라고 요청하면 HTML 웹페이지도 만들어줘요
  • 저장소(Repository)의 Settings에서 Pages 메뉴를 켜기만 하면, 주소가 자동으로 만들어져서 누구나 접속해 볼 수 있어요
  • 매번 파일을 열어보지 않아도, 웹 주소 하나만 알려주면 결과를 바로 확인할 수 있어요
용어 설명GitHub 코드와 파일을 인터넷에 저장하고 다른 사람과 함께 관리할 수 있는 사이트  ·  GitHub Pages GitHub에 저장된 파일을 무료로 웹페이지처럼 볼 수 있게 해주는 기능  ·  저장소(Repository) 코드와 파일들을 모아두는 폴더 같은 공간
